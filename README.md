# VisionDetect 🌟

> A browser-based real-time object detection tool built with TensorFlow.js and COCO-SSD. Demonstrates live camera detection, image uploads, and intuitive object analytics—all in a responsive interface.

## 🚀 Core Highlights

- **Real-Time Object Detection**
  Detects objects live from a webcam stream with bounding boxes and confidence scores.

- **Flexible Image Input**
  Supports image uploads for testing static scenes with the same detection accuracy.

- **Dynamic Confidence Adjustment**
  Users can adjust the detection threshold for more precise outputs.

- **Annotated Output & Insights**
  Each detection is visually marked, and a live summary of object counts is displayed.

- **Responsive & Mobile-Optimized**
  Works seamlessly across phones, tablets, and desktop browsers.

- **Instant Export**
  Save annotated images directly from the interface for reporting or sharing.

## 🛠 Technology Stack

- Frontend: **HTML, CSS (responsive layout)**

- Programming: **Vanilla JavaScript**

- AI & ML: **TensorFlow.js with COCO-SSD**

- Browser-Native: **Fully client-side—no server dependencies**

## 🎯 How to Run

**1. Clone the repository:**

```bash
git clone https://github.com/MrV3nomous/vision-detect.git
cd vision-detect
```

**2. Launch a local server (Python example):**

```bash
python3 -m http.server
```

**3. Open in your browser:**

```bash
http://localhost:8000
```

**4. Upload an image or activate your camera to explore live detection.**




---


## 🎛 User Interface & Controls

- **Camera:** Turn on/off, with live detection.

- **Image Upload:** Test any static image while stopping the live feed automatically.

- **Confidence Slider:** Adjust detection sensitivity dynamically.

- **Object Summary:** Track counts of detected objects instantly.

- **Export Annotated Image:** Save your detection outputs as PNG.

- **Built for performance and clarity:**

  detection, rendering, and UI are cleanly separated within a single script.

- **Leveraged TensorFlow.js in the browser:**
  shows capability in deploying ML models client-side without server overhead.

- Demonstrates careful handling of user inputs, camera permissions, and responsive layouts, critical for real-world interactive apps.

- Demonstrates client-side ML deployment, real-time data visualization, and responsive interactive UI design.
